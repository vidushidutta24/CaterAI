# CaterAI

AI-Powered Catering Quantity & Waste Optimization SaaS

CaterAI helps commercial caterers, event planners, and banquet teams eliminate food waste and forecast precise catering quantities for large-scale events.

## Project Structure

```
CaterAI/
├── frontend/             # CaterAI Web Application (React, Vite, Tailwind CSS, shadcn/ui)
│   ├── src/              # Application source code (components, pages, services, lib)
│   ├── public/           # Static web assets and icons
│   ├── package.json      # Dependencies and scripts
│   ├── vite.config.js    # Vite configuration
│   └── components.json   # shadcn/ui configuration
├── .gitignore
└── README.md
```

## Getting Started (Frontend)

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
